### Tier 1 — best stability-target / most tractable / lowest blast radius

**T1. Harvested-OP net-node KCL-residual loss (fps-1 Term A, ALONE).**
*Mechanism:* at each harvested opamp OP (the gate's own L72 locus, already OSDI-labeled
by `scripts/v6_5_5_harvest_corridor.py`), assemble the reduced 4-node KCL of the Miller
opamp (free nodes `vtail,n1,vo1i,vout`; `examples/complex/miller_opamp_directnet.sp:23-34`)
from the NN's predicted terminal currents and penalize, per free node,
`(net NN current into node)²` evaluated **at the OSDI node voltages**.
*Why OP-stability not value:* this is the **one constraint the corridor never imposed** —
the corridor OSDI-supervised each device's *absolute* id, never the **net node current**
(the difference of two large near-equal diff-pair/mirror currents). Driving that
difference→0 forces the OSDI OP to be a genuine **KCL zero of NN currents**, i.e. attacks
the fixed-point-EXISTENCE half of 1c directly.
*First experiment / A/B:* `bsimar/losses/circuit_fixedpoint.py::OpampKCLResidualLoss`
(KCL term only, **no** loop-Jacobian term), `--opamp-kcl-residual`, `lam∈{0.05,0.1,0.3}`,
harvested-opamp rows hard-masked (a `sample_class`); reuse the `create_graph=True`
autograd pattern at `bni_mae.py:216`; gate per the protocol above.
*Complexity:* medium (no inner solve, no double-backward; closed-form sum of squared net
currents). *Odds:* ~20-30 % (the existence half only; says nothing about local
contraction). *Risk to the 15:* low IF hard-masked to opamp rows + small `lam`; the
opamp-shaped surface could still bend the switchcap/ring locus → full-matrix gate is
mandatory.

**T2. Disagreement-gated autograd↔head Jacobian blend (L2), inference-only, no retrain.**
*Mechanism:* the solver consumes the **autograd** `d(id)/dV` (`mosfet_nn.py:346-351`),
which drifts 20-70 % from the separately-predicted-and-supervised gm/gds head in the
high-gain saturation band the opamp lives in. Return a per-channel convex blend
`g = (1-w)·g_autograd + w·g_head` with `w = smoothstep(rel_mismatch; lo, hi)` so
`w→0` (byte-identical) everywhere the two agree (cutoff, triode, the inverter-VTC
corridor the 15 gates ride) and `w→1` only in the drifted high-gain slab.
*Why OP-stability not value:* edits **only the consumed linearization** (id value surface
untouched, no retrain) — so it cannot fall into the id-Sobolev collapse trap — and confines
the corrected loop small-signal return-difference to exactly the node where the stamped
Jacobian is wrong.
*First experiment / A/B:* env knobs `PYCIRCUITSIM_COND_BLEND_LO/HI` defaulting to `1.0/1.0`
(== pure autograd, byte-identical ship) mirroring the existing `_GDS_FLOOR_K`/`_REV_TAPER`
pattern (`mosfet_nn.py:57-69`); sweep `(lo,hi)` on `verify_complex_opamp --tech TSMC7`,
promote any PASS to the full matrix + re-run `verify_nn_ac` (the blended gds shifts f3db).
*Complexity:* low (one env-gated edit, no GPU). *Odds:* low (~15-25 %) — **caveat:** a
Jacobian-only edit cannot manufacture a fixed point the residual lacks, and 1c shows the
high-gain point is not even a KCL residual zero of NN currents; S10 already found
more-accurate gds inert/harmful to gain. *Risk to the 15:* the blended J is NR-inconsistent
(degrades quadratic→linear convergence) on a known-multistable opamp → strict
authoritative-gate replication required (S19 lesson; `v648-gate-cpu-vs-cuda-basin`).
*Triage value:* cheapest probe in the whole agenda → run it as a fast falsifier before any
GPU spend, even though its prior is low.

### Tier 2 — promising but harder (training-time, makes the OP an attractor by construction)

**T3. Unrolled-Newton OP-attractor loss on the diff-pair+mirror sub-cell (fps-2).**
*Mechanism:* build a tiny differentiable MNA (K=2-4 damped Newton steps) of the
balance-critical sub-cell (Mn1/Mn2 + Mp3/Mp4 + tail Mn5; 3 nodes `vtail,n1,vo1i`) using
the **same** id/`d(id)/dV` stamps the production solver uses (`mosfet_nn.py:346-364`,
incl. the gds floor), initialize from a jittered OSDI OP, run K steps inside the autograd
graph, penalize `‖v_K − v_OSDI‖² + β·relu(‖v_K−v_OSDI‖ − ρ‖v_0−v_OSDI‖)`, `ρ<1`.
*Why OP-stability not value:* this **optimizes the spectral radius of the Newton update map
at the OP (<1)** — the literal definition of local fixed-point contraction, and the
complementary fix to the 1c verdict (1c is the inference-side version of this exact unroll,
`diag_opamp_basin_seed.py:61-80`). It edits the **attractor**, not the seed (1c-dead) or
the point value (corridor-exhausted).
*First experiment / A/B:* `bsimar/losses/unrolled_newton.py::DiffPairAttractorLoss`,
`--diffpair-attractor`, `K=3`, small `lam`, opamp-tagged rows only; **validate on the FULL
`verify_complex_opamp` gate, not the sub-cell** (transfer risk); kill fast if the device
DC/AC gate regresses. *Complexity:* high (backprop-through-solve / double-backward; cap K,
add GMIN+gds-floor to the training stamps, consider implicit-diff if ill-conditioned).
*Odds:* moderate-but-uncertain — best-in-class IF anything closes an unstable-FP gate.
*Risk to the 15:* the contraction Jacobian is built from the same autograd columns
id-Sobolev collapsed the opamp on → the bet is that the **coupled multi-step** framing
escapes that trap; verify it does NOT reproduce the id-Sobolev collapse before trusting it.

**T4. Current-mirror ratio + tail-balance relational constraint (mirror-ratio).**
*Mechanism:* supervise the **ratio/sum** relations a mirror and a tail-balanced pair
enforce (`|id(Vgs,Vds_a)/id(Vgs,Vds_b) − OSDI_ratio|` for Mp3/Mp4 sharing a gate; arm-sum =
tail for Mn1/Mn2) on matched-geometry tuples drawn from the gain corridor, in asinh-stable
log-ratio space, corridor-masked.
*Why OP-stability (indirectly):* a drifted effective mirror ratio gives the diff-pair's
balance node no consistent KCL solution → vo1i rails (the 1c symptom). Pinning the ratio
makes the mirror reflect faithfully so the balanced node becomes a consistent zero. It
constrains a **relative algebraic relation across two devices** (which the per-device
value-MAE never pins), and leaves each per-device slope free (so it is not the id-Sobolev
slope lever).
*First experiment / A/B:* `MirrorBalanceLoss`, `--mirror-balance`, `lam∈{0.03,0.1}`,
matched tuples precomputed into the dataset at the opamp's vo1i/vout operating Vds; success
probe = `diag_opamp_op_decomp` basin_delta over `vtail/n1/vo1i` drops below the BASIN_TOL.
*Complexity:* medium. *Odds:* low-moderate (~15-25 %) — **honest caveat:** the supervised
quantity is still pointwise id reparameterized as a ratio, so it largely re-treads the
corridor; 1c proved the failure survives being handed the exact balanced node voltages, so
a value/relational lever that "leaves the slope free" targets a DOF the diagnostic partly
ruled out. *Risk to the 15:* a scale-free term kept sub-dominant to MAE is bounded, but
enforcing ratio=OSDI in the SC/mirror-saturation regime can shift other basins → gate all
4 complex circuits. Run only after the cheaper Jacobian-targeting levers (T2) are spent.

### Tier 3 — speculative (highest build cost / widest blast radius / strongest framing risk)

**T5. Assembled-loop-Jacobian / fixed-point distillation loss (fps-1 Term B + WC1).**
*Mechanism:* beyond T1's residual, also match the reduced 4×4 nodal Jacobian `G=dF/dv`
(or its `trace<0/det>0` sign-definiteness on the diff-pair/CS node-pairs) assembled from

*Why it is Tier-3 not Tier-1:* `G` is a **fixed linear (incidence chain-rule) map of the
very per-device gm/gds that id-Sobolev COLLAPSED the opamp on** — a constrained variant of
a closed dead-end, not a mechanistically distinct lever. List it only as the **second
half** to bolt on **after** T1's residual term is shown to help in isolation; never ship
Term B without Term A proven first. *Odds:* low as a standalone; *risk to the 15:* high
(re-imports the id-Sobolev collapse risk + high build cost: hardcoded topology in the loss,
per-row device tagging, ≥7 `create_graph` rows/instance).

**T6. Adversarial solver-in-the-loop fine-tune (WC3) / uncertainty-gated in-slab
substitution (WC2).** *Mechanism (WC3):* min-max — unroll K Newton steps of the real
opamp KCL from a worst-case perturbation (1-step power iteration on the loop Jacobian
picks the rail eigenvector), train the surface to make that direction restoring; a
training-time edit that changes the SURFACE so the solver map contracts (distinct from the
1c-dead inference-time OP-seed). *Mechanism (WC2):* region-gate the in-slab terminal
current/Jacobian toward a balance-symmetric reference only where an epistemic-uncertainty
head fires. *Why Tier-3:* WC3 is the riskiest realization (training-unstable
