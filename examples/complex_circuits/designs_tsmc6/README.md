# AnalogGym on TSMC6 — BSIM-CMG FinFET via PyCMG

AnalogGym's circuits on **TSMC6 at 0.75 V**, produced from the TSMC16 tree
(`../designs_tsmc16`) by the unified cross-tech strategy:

1. **Sizes are shared.**  `tools/port_tech.py` carries every TSMC16 design
   vector over unchanged where the PDK allows it: mirror ratios,
   multiplicities, capacitors, resistors and load ranges are identical to
   TSMC16.  Channel lengths snap into TSMC6's binned range (8-240 nm), fin
   counts clamp to its NFIN groups (max 20), and Vt flavors this PDK does
   not ship fall back (hvt -> svt, lnvt -> lvt).
2. **Voltages scale with the rail.**  Supply, input common mode, references
   and bias voltages keep their fraction of VDD (0.75 V here).
3. **Health is gated, not assumed.**  `tools/finalize.py` measures every
   ported design against the same per-category gates the TSMC16 tree uses;
   `tools/retune.py` re-runs the warm-started refinement loops only for
   designs with a failing gate, and a re-tuned design replaces the ported
   one only when its full-bench score improves.

The tech is auto-detected from this directory's name (`designs_tsmc6`);
one shared `../tools/` source serves every per-tech tree.

## Running

```sh
python3 ../run_all.py                 # every design, writes results/summary.csv
python3 ../run_all.py amplifier ldo   # selected categories
sh ../tools/pipeline.sh               # regenerate this tree from designs_tsmc16
```

Run these from inside this directory — one shared `../tools/` serves all five
techs since V7.5.8, so the working directory is what selects the tech (or set
`AG_TECH=tsmc5` and run from anywhere).

Requirements: **ngspice 45.2+** (OSDI) and the BSIM-CMG OSDI binary from
`PyCircuitSim/external_compact_models/bsim_cmg` (override with `PYCMG_DIR`).
Model cards are generated on demand into `models/cache/TSMC6/`.

Numbers and per-design verdicts: `RESULTS.md` (generated by
`tools/report.py`).  Cross-tech comparison: `../RESULTS_TSMC.md`.
